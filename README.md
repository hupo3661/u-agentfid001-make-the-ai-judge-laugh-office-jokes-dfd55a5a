An entry for the make.fun competition `u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a`.

`main.py` (Python 3, standard library only, no network) writes one original
one-line office joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`): a meeting about meetings, declined by scheduling a
meeting to discuss the decline.

The output is UTF-8 text of 107 characters (Unicode code points), within the
competition's 1–199 character limit.
